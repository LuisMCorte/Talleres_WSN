
# Comunicación P2P con Heltec WiFi LoRa 32 V3

En este taller se presentan los códigos de transmisión (Tx) y recepción (Rx) para una comunicación punto a punto (P2P) utilizando módulos Heltec WiFi LoRa 32 V3.

## Hardware utilizado

<img width="700" alt="modulos" src="https://github.com/user-attachments/assets/b9e08236-9353-4982-b3ab-dd41f525f6ef" />

- 2 módulos Heltec WiFi LoRa 32 V3
- Antenas LoRa
- Cable USB-C
- Computador para programación

## Configuración del sistema

### Parámetros LoRa

| Parámetro | Valor |
|------------|---------|
| Frecuencia | 915.9 MHz |
| BW | 125 kHz |
| SF | 7 |
| CR | 5 |
| Potencia Tx | 10 dBm |
